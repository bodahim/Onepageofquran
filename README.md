# صفحة واحدة من القرآن كل يوم — دليل النشر والتخصيص (مجاني بالكامل)

تطبيق ويب (PWA) يعرض مصحف المدينة النبوية بخط مجمع الملك فهد (604 صفحة، 15 سطرًا، نفس ترتيب الطبعة)، ويتابع ورد كل مستخدم ويذكّره يوميًا بالصفحة التالية.

## ما الذي يعمل فورًا وما الذي يحتاج إعدادًا

| الميزة | بدون إعداد | بعد إعداد Firebase (الخطوة 3) |
|---|---|---|
| المصحف كاملًا + الفهرس + التنقل بالسحب | ✅ | ✅ |
| حفظ الورد والتقدم والأيام المتتالية | ✅ | ✅ |
| تذكير عبر تقويم الجوال (يفتح على وردك) | ✅ | ✅ |
| تسجيل الدخول (Google أو البريد) واسترجاع السجل في جوال جديد | ❌ | ✅ |
| إشعار يومي برقم «الصفحة التالية» واسم السورة | ❌ | ✅ |
| عدم الإزعاج إن قرأ المستخدم وردَه ذلك اليوم | — | ✅ |

---

## الخطوة 1: رفع الملفات إلى GitHub (مجاني)
1. أنشئ حسابًا في github.com ثم **New repository** باسم مثل `wird` واجعله **Public** (العام مطلوب ليبقى التذكير المتكرر مجانيًا بلا حدود).
2. اضغط **Add file › Upload files** وارفع كل محتويات المجلد (مع مجلدَي `icons` و`scripts`).
3. مجلد `.github` قد يُخفى عند الرفع من الجوال: أنشئه يدويًا عبر **Add file › Create new file** واكتب الاسم `.github/workflows/reminders.yml` والصق محتوى الملف.

## الخطوة 2: الرابط والدومين المجاني
**الخيار الموصى به — Cloudflare Pages (اسم تختاره أنت):**
1. ادخل dash.cloudflare.com › **Workers & Pages › Create › Pages › Connect to Git** واختر المستودع.
2. **Project name** = اسم رابطك، مثل `wird-quran` ← يصبح الرابط `https://wird-quran.pages.dev`.
3. اترك أمر البناء فارغًا ومجلد الإخراج `/` ثم **Deploy**. أي تعديل ترفعه على GitHub يُنشر تلقائيًا.
> اسم `pages.dev` لا يتغير بعد الإنشاء؛ لتغييره أنشئ مشروعًا جديدًا باسم آخر (مجانًا).

**البديل — GitHub Pages:** Settings › Pages › Branch: `main` ← الرابط `https://اسمك.github.io/wird`.

**دومين خاص (مثل wird.sa):** الاستضافة تبقى مجانية، لكن شراء الدومين نفسه مدفوع (سنويًا). تربطه من **Custom domains** في Cloudflare.

## الخطوة 3: تفعيل الحسابات والإشعارات (Firebase — خطة Spark المجانية بلا بطاقة)
1. console.firebase.google.com › **Add project** (بدون Analytics).
2. **Build › Authentication › Get started › Sign-in method** وفعّل ثلاث طرق: **Anonymous** و**Email/Password** و**Google** (في Google اختر بريد الدعم ثم Save).
3. **Build › Firestore Database › Create database** (Production mode) ثم تبويب **Rules** والصق محتوى `firestore.rules` › Publish.
4. **Project settings (⚙️) › General › Your apps › Web (</>)** › سجّل التطبيق وانسخ قيم `firebaseConfig`.
5. **Project settings › Cloud Messaging › Web Push certificates › Generate key pair** وانسخ المفتاح.
6. افتح `config.js` على GitHub (✏️) والصق القيم في `firebase` و`vapidKey`.
7. **Authentication › Settings › Authorized domains** › أضف دومينك (مثل `wird-quran.pages.dev`).
8. **Project settings › Service accounts › Generate new private key** ← ينزل ملف JSON (سرّي، لا ترفعه للمستودع).
9. في GitHub: **Settings › Secrets and variables › Actions**:
   - تبويب **Secrets** › New: الاسم `FIREBASE_SERVICE_ACCOUNT` والقيمة = محتوى ملف JSON كاملًا.
   - تبويب **Variables** › New: الاسم `APP_URL` والقيمة = رابط تطبيقك، مثل `https://wird-quran.pages.dev/`.
10. **Actions** › فعّل الـ workflows › افتح «تذكير الورد اليومي» › **Run workflow** للتجربة.

## تغيير الاسم والخصائص
- `config.js`: الاسم، الوصف، ألوان الصفحة والخط (`colors`)، الوقت الافتراضي، نص الإشعار ونص المشاركة.
- `manifest.json`: `name` و`short_name` (الاسم تحت الأيقونة بعد التثبيت) و`theme_color`.
- `icons/`: استبدل الصور بنفس الأسماء والمقاسات (192 و512).
- بعد أي تعديل كبير غيّر `VERSION` في `sw.js` (مثل `wird-v4`) ليصل التحديث للمستخدمين فورًا.

## كيف يعمل حفظ السجل
- قبل الدخول: السجل محفوظ على الجهاز فقط.
- عند الدخول لأول مرة: يُرفع سجل الجهاز إلى الحساب كما هو.
- عند الدخول من جوال جديد: يُعتمد **السجل الأكثر تقدمًا** (عدد الختمات ثم الصفحات المقروءة)، فلا يضيع تقدم المستخدم حتى لو قرأ صفحة في الجوال الجديد قبل الدخول.
- التذكير يصل لكل أجهزة المستخدم التي فعّل فيها الإشعارات، وإيقافه من جهاز لا يوقفه في البقية.

## ملاحظات صريحة يجب معرفتها
- **الدخول بـ Google على الآيفون:** إذا ثُبّت التطبيق على الشاشة الرئيسية قد لا تفتح نافذة Google أحيانًا؛ الدخول بالبريد يعمل دائمًا.
- **الآيفون:** الإشعارات تعمل فقط بعد «إضافة إلى الشاشة الرئيسية» وفتح التطبيق من الأيقونة (iOS 16.4+). التطبيق يعرض هذا التنبيه للمستخدم تلقائيًا.
- **دقة التوقيت:** جدولة GitHub قد تتأخر عادة دقائق، وأحيانًا أكثر وقت الضغط. مناسب لتذكير ورد، غير مناسب لمواعيد دقيقة.
- **حدود المجانية:** Firestore المجاني ≈ 50 ألف قراءة و20 ألف كتابة يوميًا؛ كل مستخدم مسجّل يستهلك تقريبًا قراءة وكتابتين يوميًا ← يكفي **عدة آلاف من المشتركين النشطين بالإشعارات**. القراءة بدون إشعارات غير محدودة. عند تجاوزها تتوقف الكتابة لبقية اليوم ولا تُخصم أي رسوم على خطة Spark.
- **مصدر النص:** صفحات المصحف تُعرض بخطوط مجمع الملك فهد (QCF) وبيانات Quran.com المفتوحة، وتُحفظ على الجهاز بعد فتحها أول مرة لتعمل دون إنترنت.
- **الصيانة:** الـ workflow يضيف commit فارغًا كل 45 يومًا حتى لا يوقف GitHub الجدولة بسبب الخمول.
